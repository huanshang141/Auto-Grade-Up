# 编辑器采用 Tauri 桌面程序；长期方向为自主实现完整界面

- 状态：accepted（2026-08-29）；修订 ADR-0001 中「单文件本地网页」的形态决策

规则编辑器需要读写本地文件（规则文件、字段对照文档），单文件网页受浏览器安全限制（本地文件读取受限，字段对照文档只能靠用户手动拖入），使用体验与分发都不理想；做进 MFAAvalonia 依旧不可行（无扩展点，复制改造成本不成比例，见 ADR-0001）。因此编辑器采用 Tauri：网页界面加原生外壳，原生读写文件、打包体积小，目标平台仅 Windows（由游戏端决定）。代价是仓库引入 Rust 与前端构建工具链，且格式定义需要从 Python 侧导出 JSON Schema 生成物供编辑器消费——生成物不手工编辑，修改格式时先改 Python 侧再重新导出。

长期方向：自动化核心稳定后，完全自主实现图形界面、替代 MFAAvalonia。解耦原则（规则 JSON 文件是唯一契约）为此铺路；触发条件与节奏另行评估，不作为当前承诺。

## Considered Options

- PySide6 桌面程序 —— 拒绝：单一事实源优势明显（直接导入 Python 侧格式定义），但界面精致度需要高额投入且观感不符合预期。
- Avalonia（C#）—— 拒绝：引入第三个语言栈，格式定义仍需副本。
- 单文件本地网页 —— 被本决策取代：本地文件访问受限，字段对照文档只能手动拖入。
- Tauri 桌面程序 —— 采纳。
