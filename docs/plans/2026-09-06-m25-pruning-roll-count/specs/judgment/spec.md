# 强化判定求值语义契约

- 消费者：执行机构（M3，两处调用：列表初扫与每回合后）、报告（M4，消费 trace）
- 依据：ADR-0003（单一规则集与无状态求值）、ADR-0006（词条数值条件的可达性语义）
- 本契约被后续版本静默破坏即视为回归

## 输入与输出

- 输入：条件树（`dict`，格式见 `docs/specs/rule-file-format.md`）+ `Artifact`（数据模型）+ 游戏档案（`GameProfile`，代号与参数来源，见 `docs/specs/game-profile.md`）+ 可选的次数规则树（`roll_rule`，M2.5 起）
- 输出：`Judgment`，含 `passed`（布尔）与 `trace`（字典树）
- 求值接口：`evaluate(rule, artifact, profile, roll_rule=None)`——`roll_rule` 为 None 时不求值次数体系（列表初扫）；传入时两棵树都求值，`passed` 为两者与合并。调用方显式声明求值时机：执行机构持有界面知识（ADR-0005），次数数据仅在强化页可读

## 无状态承诺

- 同一输入永远得到同一输出；求值不修改输入、不读写模块级可变状态、不记住任何跨调用历史
- 单件圣遗物被重复求值（重复扫到、报告重放）结果不变

## 剩余强化次数

- `remaining_rolls = ⌈(等级上限 − 等级) ÷ 词条变动间隔⌉`，向上取整——等级可能停在非节点上（如原神 +17 到 +20 仍有一次变动）；参数取自游戏档案（原神为 ⌈(20 − 等级) ÷ 4⌉）
- 恒存在，由等级与档案参数现场推导，不入数据模型

## 词条数值条件的可达性口径（M2.5 起，ADR-0006）

- `sub.<代号>` 与 `roll.<代号>` 的求值实际值为**乐观可达值**——在最有利的成长分配假设下，该词条到等级上限为止能达到的数值上界；规则要求的是「强化到底能否达到」，达成无望即提前止损（强化剪枝）
- 推导（纯函数，参数取自档案）：剩余变动点数 R = ⌈(等级上限 − 等级) ÷ 间隔⌉；未来必解锁数 U = min(副词条上限 − 已解锁条数, R)，含待激活词条的转正（副词条未满上限时下一变动点必解锁，L1 预览与 E7 样本佐证）；可分配成长次数 budget = R − U
- `sub.<代号>` 可达值 = 词条当前值 + budget × 档案单次成长上限（`roll_growth_max`）；待激活词条的当前值即预览值
- `roll.<代号>` 可达值 = 当前强化次数 + budget；当前次数取自词条值对象（`roll_count`），为 null（未知）时按缺失处理
- 4 星暂不支持：查上限表无该星级数据 → `ProfileError` 立即停止

## 字段求值规则

- 数值按游戏显示值比较（攻击力 298、暴击率 5.8）；词条数值条件的实际值为可达值（上节），其余字段为当前值
- `slot` 按部位代号精确比较；`set` 按套装名游戏原文精确比较
- `substat_count` = 已解锁副词条条数（不含待激活行，上限为档案 substat_max）
- `main.<代号>` 取主词条数值——主词条成长是确定性的，维持当前值口径（M2.5 不做可达重写）
- `roll.<代号>` 在副词条中检索该代号的强化次数；次数规则体系仅在 `roll_rule` 树内可用

## 缺失语义

- `main.<代号>` 与 `sub.<代号>` 不存在时：任何数值比较结果为不通过（不抛错）；`exists` 判定为假
  - `main.<代号>` 仅当主词条恰为该代号时存在（例：主词条为攻击力百分比的圣遗物上，`main.crit_rate` 缺失）
  - `sub.<代号>` 仅当该代号在已解锁或待激活副词条中出现时存在；待激活词条视为存在（词条种类已由游戏预生成，`exists` 为真、数值条件按预览值起算的可达值求值）
- `roll.<代号>` 存在性同 `sub.<代号>`；词条 `roll_count` 为 null（未知）时数值比较不通过、`exists` 为真
- 恒存在字段仅六个：`level` `rarity` `slot` `set` `substat_count` `remaining_rolls`，对它们使用 `exists` 恒为真

## 空数组语义

- `all: []` → 通过
- `any: []` → 不通过

## trace 形状

字典树，M2.5 起顶层为两棵子树：

```jsonc
{ "rule": { /* rule 树的求值 trace，与条件树同构 */ },
  "roll_rule": null  /* 未传入次数规则时为 null，传入时为其求值 trace */ }
{ "kind": "all", "passed": true, "children": [ /* 子节点 trace */ ] }
{ "kind": "leaf", "passed": false, "field": "sub.crit_rate", "op": ">=", "value": 15,
  "actual": 22.6,
  "derivation": { "current": 3.1, "budget": 5, "growth_max": 3.9 } }
```

- 词条命名空间（`sub.*`、`roll.*`）的叶子 trace 额外携带 `derivation`（当前值或当前次数、可分配成长次数、成长上限），保证剪枝决策可解释、可重放；其余叶子无该键
- `roll_rule` 子树内叶子的 `derivation` 形状为 `{"current_rolls": <当前次数>, "budget": <可分配成长次数>}`
- exists 叶子无 `value` 键；`actual` 为字段存在时的实际数值、缺失时为 `"missing"`
- 每个 `passed` 可由该节点与子节点的记录独立复核——报告里的每个决策可解释、可重放
