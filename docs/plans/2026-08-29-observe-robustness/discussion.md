# 观测机构强化页稳健性讨论记录（2026-08-29）

> 性质：M2 验收后的补强讨论底稿，供后续契约修订、解析实现与 M3 设计引用。
> 已确认结论的正本在 `docs/specs/observation.md`（强化页的读取时机与行形态节），
> 决策沉淀到 `docs/adr/` 与 `CONTEXT.md` 时以那些文档为准，本文不保持现行口径。

## 起因

第二批补拍（`reference/pic3`）验收发现：`E5_enhance_lv8_preview.png` 是强化
执行机构**刚完成一次强化**的界面——第 4 条副词条显示「防御力 5.8% → 11.1% ↑」。
此前 18 张夹具全部是静止形态，问题因此暴露：单件强化流程中，强化页读取器的
主要使用时机恰是「每个强化回合结束后重新读取、判定是否继续」，若解析核心
不支持结算形态，每个经过词条成长的回合都无法判定（整行读取失败）。

## 讨论过程中的形态盘点（含被需求方否定的一档）

初始分析按四个时机盘点强化页形态：

| 时机 | 初始假设的形态 | 后续结论 |
| --- | --- | --- |
| 进入强化页、尚未放入素材 | 静止单值 | 成立 |
| 放入素材后、未点强化 | 假设有「旧值 → 新值 ↑」预览 | **被否定**：界面无任何变化 |
| 强化结算后 | 「旧值 → 新值 ↑」 | 成立，且为回合后读取的常态输入 |
| 满级 +20 进入强化页 | 素材区形态未采样 | 形态未知，判定所需字段不受影响（低风险） |

## 需求方纠正与补充（2026-08-29，原文要点）

1. **不存在「放入素材后预览」阶段**：放入素材后、未点强化时界面不会有任何
   变化；只有点击强化、等待一两秒强化完成之后，才会出现「旧值 → 新值 ↑」。
2. **结算标记长期保留**：「旧值 → 新值 ↑」在强化页面中一直保留，直到新的
   强化完成（更新）或者退出强化界面。
3. **强化次数的重要性**：除了数值，词条的强化次数（roll 次数）未来也可能
   进入决策——计划在决策机构中推出强化剪枝（提前放弃不可能达到规则要求的
   圣遗物），以及另一套规则体系（规则表现为设置词条的强化次数）。

## 分析结论（已落契约正本）

- 「等待标记消退」方案被排除（标记不自动消退），契约修订是唯一路径。
- 同一「双数值行」视觉不存在语义二义性的来源（无预览态），解析取**新值**
  （当前值）即可，无需感知时机；但解析仍不依赖箭头符号（按数值个数判断），
  防箭头误读。
- 读取时机纪律归执行机构（M3）：只在「进入未放入」与「结算后」两个时机
  调用强化页读取器；时序异常由等级核对兜底（安全停止），不属于解析核心。
- 带圈数字标记与结算标记互相独立、长期保留，清洗约定不变。

## 未来方向：强化次数的观测来源（开放，待细化）

需求指向：决策机构未来需要「每个词条的强化次数」。候选来源各有待验证问题：

1. **界面标记识别**：词条旁的带圈数字若语义可考（如获得节点序号或 roll
   次数），OCR 可读——但现行清洗规则把它删除，需要改为保留并解析；E4
   （四条全 ①）与 fig2（②攻击力、①生命值）的语义尚未定论。
2. **数值反推**：词条当前值 = 初始值 + 若干次随机区间成长，无法精确反推
   roll 次数，只可能给出候选范围。
3. **执行机构记账**：回合间 diff 词条数值变化本地累计——只对「全程跟随
   强化」的圣遗物有效；列表页扫描遇到的圣遗物无历史可记，两个读取器的
   输出一致性（ADR-0005 同一数据模型）如何维持需要设计。

以上开放问题在拷问（grilling）环节逐项细化，结论落 ADR 与 CONTEXT.md。

## 第一轮拷问结果（2026-08-29）

**查证结论（带圈数字语义定论）**：带圈数字 ①②③ 是词条被强化的次数显示，
原神 5.3 版本（「炽烈的还魂诗」）官方新增功能，更新说明原文「圣遗物的
追加属性增加了被强化次数的数字显示」（来源：米哈游官方更新说明
ys.mihoyo.com/main/news/detail/127804）。与样本完全吻合：E4 为 5 星 +16、
四次成长分到四条、全部 ①。此前的「候选来源 1」从待验证升级为已确认的
数据来源；「候选来源 3」（执行机构记账）不再必要。
