# 观测解析（observation）契约

- 消费者：执行机构（M3，ReadArtifact 接线层）、运行报告（M4，ReadResult 序列化）
- 上游约束：M2 计划的 `concept.md`（职责分界，归档于 `docs/plans/archive/`）、主 spec §6（识别区域）、ADR-0004 / ADR-0005
- 本契约被后续版本静默破坏即视为回归

## 解析核心接口

- 模块 `agent/observe.py`；**禁止导入 maa**（冒烟测试守卫，理由见 `concept.md` §3.1）
- 输入三样：识别结果集、`GameProfile`（M1 产物）、`Textmap`（字段对照文档加载产物）
- 识别结果集：`dict[区域键 → list[文字框]]`；文字框形如
  `{"box": [x, y, w, h], "text": str, "score": float}`（score 0.0~1.0）；
  模板匹配区域（stars/lock）无文字，text 为空串
- `read_list(recognition, profile, textmap) -> ReadResult`：列表页读取器
- `read_enhance(recognition, carried, profile, textmap) -> ReadResult`：强化页读取器；
  `CarriedFields(rarity: int, set: str, locked: bool)` 由控制层从列表初扫传递（ADR-0005）

### 区域键

| 列表页读取器 | 内容 |
| --- | --- |
| `name` | 圣遗物名 |
| `slot` | 部位名 |
| `main` | 主词条行（名+值） |
| `level` | 等级（如 +19） |
| `substats` | 副词条 0~4 行 |
| `set` | 套装名（绿色文字行） |
| `stars` | 星级图标（TemplateMatch） |
| `lock` | 锁定图标（TemplateMatch） |

| 强化页读取器 | 内容 |
| --- | --- |
| `breadcrumb` | 面包屑「部位 / 圣遗物名」 |
| `main` | 主词条行 |
| `level` | 等级 |
| `exp` | 等级内经验进度（如 2900/35575） |
| `substats` | 副词条 0~4 行（强化次数标记被忽略） |
| `mora` | 本次强化摩拉 |
| `fodder_tier` | 素材档位文字（如 4星及以下素材） |

## ReadResult

| 字段 | 语义 |
| --- | --- |
| `ok` | 布尔；failures 非空即 False |
| `artifact` | 圣遗物属性（spec §3 模型）；ok 时必有，否则 None |
| `extras` | 附属读数：强化页含 `exp`、`mora`、`fodder_tier`、`fingerprint`（`{"slot": …, "name": …}`）；列表页可为空 dict |
| `confidences` | 逐字段置信度，取该字段所用文字框分数的最小值 |
| `failures` | 读取失败清单，逐条人类可读 |
| `warnings` | 警告清单（只进报告，不拦截） |

- 无状态：同输入两次调用结果相同；不修改输入
- 解析前置条件：`validate(规则)` 之外的档案已加载；本契约不依赖规则文件

## 字段组装规则

- 列表页：星级 = stars 区域命中数（1~5）；锁定 = lock 区域有命中；其余字段取 OCR
- 强化页：面包屑按「/」切分为部位名与圣遗物名（部位参与组装，两者进 `extras.fingerprint`）；
  等级、主词条、副词条现场读取；rarity / set / locked 取自 CarriedFields
- 词条行解析：行文本切分为（词条名文本，数值文本）——两界面格式分别为「名+值」连写
  （如「暴击率+3.1%」）与「名 值」同行（如「暴击率 3.1%」）；数值经 M1 解析函数
  （先去空白、字符白名单），千位分隔符逗号在解析前去除（固定值大数值显示为「3,967」，
  2026-08-29 补拍核验）；词条名经对照文档映射到文字族，双代号族（hp/atk/def）
  按 % 后缀落 `_percent` 代号，单代号族原样
- 「待激活」行不参与解析：3 词条圣遗物的第 4 条在两个界面均以灰色
  「×××（待激活）」预览行显示（2026-08-29 补拍核验）；行文本含「待激活」标记即整行
  丢弃，不计入副词条行数、代号与数值
- 强化次数标记（①②③）不参与解析（契约：忽略）

## 强化页的读取时机与行形态

- 强化页的副词条行存在两种形态：静止单值（如「暴击率 3.1%」）与成长结算形态
  （如「防御力 5.8% → 11.1% ↑」，箭头右侧是本次强化成长后的数值）
- 放入素材后、点击强化前，界面无任何变化（2026-08-29 需求方确认，不存在
  预览形态）；点击强化并等待强化完成（约一两秒）后，本次成长的词条出现结算形态
- 结算标记长期保留：直到下一次强化完成（标记更新）或退出强化界面
  （2026-08-29 需求方确认）；因此「等待标记消退后再读取」不可行，解析必须
  直接支持结算形态。标记整批刷新：每次强化完成后，只有本次成长的词条带
  结算标记，上一回合的标记消失；退出强化界面后再进入为静止单值形态
  （2026-08-29 需求方确认）
- 结算形态的解析语义：行内出现两个数值（旧值与新值）时，取最后一个（新值）
  入模——强化已完成，新值是当前值；判断依据是数值个数，不依赖箭头符号的
  识别结果（箭头可能被 OCR 误读或漏读）。此形态仅出现在副词条行：主词条
  行强化后只显示新值、无前后对比（2026-08-29 需求方确认）；列表页不存在
  此形态
- 强化页读取器的调用时机由执行机构约束（M3 落地）：仅在「进入页面未放入
  素材」与「强化结算后」两个时机读取，放入素材与点击强化之间不读取。
  该纪律保证双数值行的语义唯一（结算）；时序异常由执行机构的等级核对兜底，
  不属于解析核心
- 带圈数字标记（①②③）是词条被强化的次数显示——原神 5.3 版本（「炽烈的
  还魂诗」）新增的官方功能，更新说明原文「圣遗物的追加属性增加了被强化
  次数的数字显示」（2026-08-29 查证）。该标记与结算标记互相独立、长期
  保留，仅强化页与角色对比界面显示、列表页不显示。现行版本在识别结果中
  保留该标记、解析时剥离、不入数据模型；读取入模（词条强化次数）随 M3
  单件流程落地——2026-08-29 需求方定案：强化剪枝（提前放弃不可能达到
  规则要求的圣遗物）与「规则设置为词条强化次数」的规则体系在 M3 内考虑

## 未知与缺失语义

- 词条名未收录对照文档 → 名称按 OCR 原文存入 + warning（安全方向：无代号可匹配，判定天然不通过）
- 部位名未收录 → 读取失败
- 必要区域缺失或全部文字框为空 → 读取失败
  （列表页必要：name/slot/main/level/substats/set/stars；强化页必要：breadcrumb/main/level/substats）
- 副词条行数 > `profile.substat_max` → 读取失败
- 副词条代号重复 → 读取失败（2026-08-29 定案）；「重复」以适配后的属性代号为准——
  同一文字族的固定值与百分比是两个代号，「攻击力+5.8%」与「攻击力+19」并存合法
  （2026-08-29 补拍核验的真实形态）
- 数值解析失败（含全角数字/全角百分号）→ 读取失败（2026-08-29 定案）
- 警告（不拦截）：副词条行数与等级一致性——合法行数预期按稀有度放宽：4 星 +0 为
  2 条、5 星 +0 为 3~4 条（2026-08-29 补拍核验），超出各稀有度的合法形态才提示
- 读取失败时 artifact 为 None；extras/confidences 尽量填充已成功字段

## 识别结果转储（测试夹具格式）

- JSON：`{"<区域键>": [{"box": [x, y, w, h], "text": "…", "score": 0.99}, …]}`
- 来源两类：真实转储（录制脚本对截图夹具跑框架识别产出）+ 构造转储（异常样例手工编写）

## 流水线节点约定

- 节点位于资源包 `pipeline/`；命名 `obs_<reader>_<region>`；OCR 节点精确 roi——单行区域
  `only_rec`，多行区域（两界面的主词条与副词条、列表页套装）用检测模式并以 `expected`
  过滤行；星级、锁定为 TemplateMatch；节点不含 action 与 next
- 节点名到区域键的映射属于录制脚本与 M3 接线层，不属于解析核心契约
